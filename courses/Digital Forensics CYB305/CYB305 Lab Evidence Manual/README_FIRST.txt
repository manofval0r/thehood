ABOUT THIS CASE
This archive contains fictional digital evidence for your Week 1 practical.
The institution, accounts, payment references and records are invented.
The IP addresses and domains are reserved for documentation examples.
Do not contact addresses, domains or services shown in the records.

BEFORE YOU START
Read CYB305_Lab_Student_Manual_Updated.pdf, supplied with this ZIP.
Keep the original downloaded evidence ZIP unchanged and record its
filename and the date and time you received it.

ARCHIVE CONTENTS
  SOURCE_EVIDENCE/           Supplied source records. Do not modify them.
  WORKING_COPIES/           Files supplied for examination.
  SHA256_SOURCE_MANIFEST.csv SHA-256 reference values for source files.
  STUDENT_REPORT_TEMPLATE.txt Report headings you may use.

INTEGRITY AND EXAMINATION
  1. Work from WORKING_COPIES/ and verify the files before relying on them.
  2. Compute SHA-256 over file bytes, not text copied into another program.
  3. Compare working-copy hashes with SHA256_SOURCE_MANIFEST.csv.
  4. If a copy differs, document the discrepancy. Verify the matching
     SOURCE_EVIDENCE file and create a fresh working copy for analysis.
  5. Support each observation using the file and event identifiers.
  6. Separate what is recorded from hypotheses and unresolved questions.
  7. A matching hash establishes byte-level agreement with the reference,
     but does not itself prove a record's origin or legal admissibility.

TIME ZONES
